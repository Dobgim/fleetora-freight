# Fleetora Freights

React, TypeScript, Vite, and Tailwind CSS application for the Fleetora Freights site.

## Run locally

```sh
npm install
npm run dev
```

Open `/` for the public website or `/admin` for the responsive operations dashboard.

The admin dashboard currently uses in-memory demo data; connect a backend to persist shipments and provide live operational metrics.

## Production build

```sh
npm run build
npm run preview
```
